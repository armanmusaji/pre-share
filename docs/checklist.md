# The pre-handoff checklist

[Back to the prototype](https://pre-share.vercel.app)

**Short version:** the same kinds of mistakes kept coming back, even after they were written down. So now the agent that didn't build a version checks it in a browser, on a phone, before Arman sees it.

## The checklist
- Who is speaking in each piece of text, the author or the fictional product? Keep demo controls out of the product.
- Try every mark that looks like a control. Remove any that don't do what they look like they do.
- Start on a phone. The first button must get you to the feature without digging.
- Compare what the product knows across screens. Don't imply it can detect or reason about things it can't.
- Check every fix against the source and the person's role. Don't hand anyone authority they never had.
- Apply, cancel from every entry point, undo, and try a change that reaches too far. Check the content, where focus lands, and the work that should stay the same.

## Does it work?
Claude ran it once on the fixed build, and none of the repeat problems came back. But the checklist was written from those same problems, so that's one data point, not proof. Project three is the real test.
